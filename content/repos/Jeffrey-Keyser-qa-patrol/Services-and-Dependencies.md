# Services and Dependencies

## Depends on (confirmed in source)

- **Pay app registry**: `pay-client.ts` calls the local Pay API ([src/services/pay-client.ts:L1](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/pay-client.ts#L1)). It resolves by ID, then by name ([src/services/pay-client.ts:L23-L49](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/pay-client.ts#L23-L49)). The `/api/v1/apps` routes proxy it ([src/routes/versions/v1/apps.ts:L8-L20](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/routes/versions/v1/apps.ts#L8-L20)).
- **Solo Vault**: a local secrets endpoint supplies Pay-auth credentials ([src/services/auth.ts:L14-L17](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/auth.ts#L14-L17)), the AI proxy key ([src/services/ai-proxy-client.ts:L2](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/ai-proxy-client.ts#L2)), a GitHub token ([src/services/github-issues.ts:L5](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/github-issues.ts#L5)), and the cron key ([src/services/cron-client.ts:L4-L5](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/cron-client.ts#L4-L5)). Each path requires `SOLO_VAULT_KEY` ([src/services/ai-proxy-client.ts:L29-L31](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/ai-proxy-client.ts#L29-L31)).
- **AI Proxy**: used for step generation with model `gpt-4o` ([src/services/ai-proxy-client.ts:L1](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/ai-proxy-client.ts#L1), [src/services/ai-proxy-client.ts:L63](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/ai-proxy-client.ts#L63)) and for vision analysis ([src/services/vision-analyzer.ts:L57-L65](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/vision-analyzer.ts#L57-L65)).
- **cron-service**: the client posts job registrations to `CRON_SERVICE_URL` ([src/services/cron-client.ts:L1](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/cron-client.ts#L1), [src/services/cron-client.ts:L81-L111](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/cron-client.ts#L81-L111)) and deletes them ([src/services/cron-client.ts:L113-L129](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/cron-client.ts#L113-L129)).
- **RabbitMQ**: optional. Publishing and consuming are enabled only when `RABBITMQ_URL` is set ([src/services/rabbitmq-publisher.ts:L17-L25](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/rabbitmq-publisher.ts#L17-L25), [src/services/rabbitmq-consumer.ts:L121-L122](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/rabbitmq-consumer.ts#L121-L122)).
- **PostgreSQL**: configured from `DATABASE_*` or `DB_*` variables ([src/config/env.ts:L36-L47](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/config/env.ts#L36-L47)).
- **System Chrome**: the runner uses `/usr/bin/google-chrome` ([src/services/playwright-runner.ts:L157](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/playwright-runner.ts#L157)). The unit sets `DISPLAY=:99` ([qa-patrol.service:L10](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/qa-patrol.service#L10)).
- **GitHub issues**: the `github-error-issues` package files issues when a repo is configured ([src/services/github-issues.ts:L1](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/github-issues.ts#L1), [src/services/github-issues.ts:L32-L36](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/github-issues.ts#L32-L36)).
- **Probe targets**: probe defaults reference Pantry, Pay login, and Stripe endpoints ([src/services/probe-runner.ts:L29-L33](https://github.com/Jeffrey-Keyser/qa-patrol/blob/f9b3dd00ba79e6fc176957326134666ddbb039b5/src/services/probe-runner.ts#L29-L33)). Whether any such probe is active is unknown.
