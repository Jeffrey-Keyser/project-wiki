# Glossary

- **Advisory.** The steward observes and explains. Tools act only when the owner grants them ([README.md:L3-L6](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/README.md#L3-L6)).
- **Grant.** An owner-authored permission loaded beside the config ([cmd/beelink-steward/configured.go:L23-L28](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/cmd/beelink-steward/configured.go#L23-L28)).
- **Suspension.** A block on a restart tool after a regression. It is cleared by `restore-grant` ([README.md:L36-L38](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/README.md#L36-L38), [README.md:L50-L52](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/README.md#L50-L52)).
- **tmp-root scope.** The `/tmp` cleanup scope, with `older_than_days` at least 7 ([README.md:L60-L61](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/README.md#L60-L61)).
- **Spool.** The fixed snapshot directory that helpers write and the sampler reads ([docs/sensing-sandbox.md:L155-L159](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/sensing-sandbox.md#L155-L159)).
- **Cadence band.** Adjacent maintenance snapshots must fall within 270 to 330 seconds ([docs/maintenance-contract.md:L81-L83](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L81-L83)).
- **Lineage.** The host, service and policy identity an exception belongs to ([store/servicehealth.go:L69-L72](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/store/servicehealth.go#L69-L72)).
- **Exception.** The single active record per lineage ([docs/unit-contract.md:L29-L32](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/unit-contract.md#L29-L32)).
- **Cooldown.** Recurrence within 24 hours, inclusive, reopens the same exception ID ([docs/durable-store.md:L53-L55](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L53-L55)).
- **Episode.** The 1-based lifecycle occurrence used for judgments ([docs/durable-store.md:L106-L109](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L106-L109)).
- **Evidence ID.** A content ID for retained evaluated windows ([docs/maintenance-contract.md:L37-L38](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L37-L38)).
- **Tool need.** A published value such as `none`, `available` or `lacked` ([docs/cpu-contract.md:L212](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/cpu-contract.md#L212), [docs/reboot-contract.md:L127](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/reboot-contract.md#L127)).
- **Dev-inbox prefix.** The fixed `dev-inbox-` name prefix that routes a proposal ([docs/unit-contract.md:L34-L36](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/unit-contract.md#L34-L36)).
- **Dev-inbox proposal.** A durable record with delivery `pending`. Local review never claims delivery ([docs/durable-store.md:L173-L185](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L173-L185)).
- **Standing suppression.** An owner-created mute on a unit's recurrence ([README.md:L92-L94](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/README.md#L92-L94)).
- **Suppression candidate.** A unit eligible for a suppression proposal ([docs/unit-contract.md:L51-L53](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/unit-contract.md#L51-L53)).
- **Judgment.** An owner `needed` or `not-needed` assessment ([docs/durable-store.md:L101-L104](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L101-L104)).
- **Action needed.** The status field that reads `unknown`, `needed` or `not-needed` ([docs/durable-store.md:L123-L124](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L123-L124)).
- **Watch start.** The first sample time for a host or boot, which never moves later ([docs/maintenance-contract.md:L103-L106](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L103-L106)).
- **Late raise.** An opening that happens long after its onset, which may record one steward miss ([docs/container-health-contract.md:L114-L118](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/container-health-contract.md#L114-L118)).
- **Incomplete window.** A window too short to qualify, which raises nothing ([docs/maintenance-contract.md:L48-L49](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L48-L49)).
- **Degraded.** A result that neither opens nor clears an exception ([docs/maintenance-contract.md:L49-L51](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L49-L51)).
- **Synthetic fixture.** A labeled test input that is never evidence about the live host ([docs/maintenance-contract.md:L176-L177](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L176-L177)).
- **Owner option.** A fixed action label, such as `inspect evidence` ([docs/maintenance-contract.md:L41-L43](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/maintenance-contract.md#L41-L43)).
- **Revision.** The committed state counter that `status.json` publishes ([docs/durable-store.md:L42-L43](https://github.com/Jeffrey-Keyser/beelink-steward/blob/4c0dad5b395f187fd67343b0af6b4119f48df1ac/docs/durable-store.md#L42-L43)).
