# Services and Dependencies

## Depends on

### External services

- **Pay auth.** Session and identity source. Wired with `setupPayAuth` using `payUrl` from config ([server/app.ts:L64](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/app.ts#L64), [server/app.ts:L87](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/app.ts#L87)). The default is `https://pay.jeffreykeyser.net` ([server/config/env.ts:L129-L130](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/config/env.ts#L129-L130)).
- **AI Proxy.** Image generation runs server-side. The service submits to `/v1/image` and polls jobs ([server/services/generationService.ts:L163](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/generationService.ts#L163), [server/services/generationService.ts:L229](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/generationService.ts#L229)). Explorations call `/v1/chat` ([server/services/explorationAgent.ts:L40](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/explorationAgent.ts#L40)). The hostname is in conflict across sources, so the deployed endpoint is unknown ([server/config/env.ts:L135](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/config/env.ts#L135)).
- **Solo Vault.** Supplies the AI Proxy key at runtime from a fixed secret path ([server/services/soloVault.ts:L3](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/soloVault.ts#L3), [server/services/soloVault.ts:L16-L20](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/soloVault.ts#L16-L20)).
- **PostgreSQL.** Sessions, images, versions, and history, in the `image_studio` schema ([server/app.ts:L209-L213](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/app.ts#L209-L213), [README.md:L193](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/README.md#L193)).
- **AWS S3.** Image objects via `@aws-sdk/client-s3` ([server/services/s3.ts:L1-L12](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/s3.ts#L1-L12), [server/package.json:L21](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/package.json#L21)).
- **NanoClaw gateway.** Optional notifications posted to `/api/v1/messages` when enabled. The default base is `http://127.0.0.1:3102` ([server/config/env.ts:L138-L139](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/config/env.ts#L138-L139), [server/services/importNotifier.ts:L158](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/services/importNotifier.ts#L158)). Whether it is deployed is unknown.
- **GitHub Packages.** Registry for `@jeffrey-keyser/*` packages, needing `GITHUB_TOKEN` at install ([AGENTS.md:L21-L23](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/AGENTS.md#L21-L23)). Docker image builds pass the token as a BuildKit secret (`id=github_token`) that is mounted only for the `npm ci` step, not stored as a build ARG or image ENV ([Dockerfile_Server#L8-L14](https://github.com/Jeffrey-Keyser/image-studio/blob/d060ceadbdaf/Dockerfile_Server#L8-L14)). `docker-compose.dev.yml` sources that secret from the `GITHUB_TOKEN` environment variable ([docker-compose.dev.yml#L104-L108](https://github.com/Jeffrey-Keyser/image-studio/blob/d060ceadbdaf/docker-compose.dev.yml#L104-L108)).
- **Cloudflare Tunnel.** Documented as the ingress for both hostnames ([README.md:L201-L205](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/README.md#L201-L205)). No tunnel config is in the excerpts.

### Internal libraries

- `pay-auth-integration` is pinned to `^6.10.1` in both server and client ([server/package.json:L29](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/package.json#L29), [client/package.json:L8](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/client/package.json#L8)). AGENTS.md limits imports to public entry points ([AGENTS.md:L8-L12](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/AGENTS.md#L8-L12)).
- `express-server-factory` builds the app ([server/app.ts:L2-L12](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/app.ts#L2-L12)).
- `api-errors` and `github-error-issues` are used for error bridging and issue creation ([server/app.ts:L14-L15](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/app.ts#L14-L15)).
- `express-middleware-suite`, `database-base-config`, `message-contracts`, and `pay-api-types` are listed in server dependencies. Their use is not visible in the excerpts ([server/package.json:L23-L28](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/package.json#L23-L28)).
- `personal-ui-kit` and `redux-app-toolkit` are client dependencies ([client/package.json:L9-L10](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/client/package.json#L9-L10)).

## Consumed by

### Confirmed by source

- **Browser SPA.** `App.tsx` routes and service modules call the API ([client/src/App.tsx:L14-L23](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/client/src/App.tsx#L14-L23), [client/src/services/historyService.ts:L10-L12](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/client/src/services/historyService.ts#L10-L12)).
- **Deploy script.** Polls `/api/v1/diagnostics/deploy` after restart ([deploy.sh:L45-L48](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/deploy.sh#L45-L48)).
- **Service-token callers.** `POST /api/v1/import` accepts `X-Service-Token` or a bearer token. The route returns 503 when no token is configured ([server/middleware/serviceAuth.ts:L31-L37](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/middleware/serviceAuth.ts#L31-L37), [server/middleware/serviceAuth.ts:L39-L45](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/middleware/serviceAuth.ts#L39-L45)).
- **Named-owner service callers.** The exploration service routes require a service token and an `X-Owner-Pay-Id` header ([server/routes/versions/v1/explorations.ts:L230-L238](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/routes/versions/v1/explorations.ts#L230-L238)). Storyboard service routes follow the same pattern ([server/routes/versions/v1/storyboards.ts:L45-L47](https://github.com/Jeffrey-Keyser/image-studio/blob/cc09e9afb77781ab37b1237f3341edbe1e5425f9/server/routes/versions/v1/storyboards.ts#L45-L47)).
